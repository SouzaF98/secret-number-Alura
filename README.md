## 💡 Sobre o Projeto

O **Jogo do Número Secreto** foi construído com o intuito de aplicar na prática os conceitos básicos e fundamentais do desenvolvimento Web e da lógica de programação. 

O jogo sorteia um número entre 1 e 10 (ou limite configurado) e dá feedback ao jogador se o número indicado é maior ou menor que o número secreto, contando o total de tentativas até o acerto.

---

## ✨ Funcionalidades

- [x] **Zero Instalação:** Funciona diretamente no navegador web.
- [x] **Acessibilidade por Voz:** Narração dos textos na ecrã em Português do Brasil utilizando a biblioteca `ResponsiveVoice.js`.
- [x] **Dicas em Tempo Real:** Indica se o número secreto é **maior** ou **menor** do que o palpite.
- [x] **Contador de Tentativas:** Exibe a quantidade exata de tentativas necessárias para acertar (com concordância no singular/plural).
- [x] **Validação e Sorteio Sem Repetição:** Guarda os números já sorteados numa lista (array) para evitar repetições numa mesma sessão.
- [x] **Botão Novo Jogo:** Reinicia a partida e gera um novo número secreto mantendo a fluidez.
